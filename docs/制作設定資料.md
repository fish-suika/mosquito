## 本人の設定資料（原文）

### 概要
蚊を操作し、人間に見つからないように血を吸う3Dステルスアクションゲーム。危険な場所ほど報酬が高く、発見された場合は攻撃を回避して逃げ切ることを目指す。

### 内容
- 視点： 三人称視点。蚊の姿を見ながら操作する。
- 舞台： 人間が1人いる部屋。
- 基本操作： 蚊の飛行、移動、吸血、攻撃回避。
- 吸血システム： 吸う場所によって難易度と報酬が変わる。足首などは低リスク、顔の近くは高リスク・高報酬。
- 発見時： 人間の攻撃が始まり、回避して逃げ切ればゲームを続行できる。
- 報酬： 吸血に成功するとスコアを獲得する。
- 目標： 発見や攻撃を乗り越え、できるだけ多くの報酬を稼ぐ。

### 制作ルール
- Unityで、まず遊べる小規模な試作品を完成させる。
- 最初は部屋1つ、人間1人で実装する。
- 数値や具体的な実装方法は、ゲーム性を損なわない範囲でClaudeが判断する。
- 実装前に作業計画を提示し、確認を待つ。
- 矛盾や重大な問題があれば、実装前に報告する。
- 完成条件を満たしたら制作を終了する。最終チェック後の修正は1回までとし、追加改善は次回候補に回す。

## 基本の遊び（Claude 案）

1. 夜の寝室。人間はベッドにいて、**寝ている／うとうと／起きている** を行き来する
2. 蚊を飛ばして人間に近づき、肌に **着地 → 左クリック長押しで吸血**。吸っている間スコアが増え続ける
3. 吸うほど人間は **かゆみ** を感じ、羽音や視界に入ることで **気づきゲージ** が溜まる。満タンで **発見**
4. 発見されると人間が起きて手で叩いてくる。**右クリックの回避ダッシュ**でかわし、視界の外（家具の陰など）に隠れて一定時間やり過ごせば **逃げ切り**。人間はまた寝始め、ゲーム続行
5. 1回でも叩かれたら **ゲームオーバー**。それまでのスコアが結果。リトライできる

## 部位ごとのリスクと報酬（Claude 案・数値は Phase 1 で調整）

| 部位 | 吸血の点（毎秒） | かゆみの溜まり方 | 備考 |
|---|---|---|---|
| 足首 | 10 | 遅い | 布団から出ていることが多い。いちばん安全 |
| 腕・手 | 20 | ふつう | 寝返りで位置が変わる |
| 首 | 35 | 速い | 顔の向きによっては視界に入る |
| 顔（頬・額） | 60 | とても速い | 目と耳に近く、羽音と視界の両方でバレやすい |

- 1回の吸血を途中でやめて飛び立つと、それまでの点は確定（**欲張りすぎずに離れる判断**がゲームの中心）
- 同じ部位を続けて吸うと、かゆみの溜まり方が速くなる（同じ場所ばかり狙わせない）

## 操作（キーボード＋マウス）

- マウス: 視点（カメラが蚊の後ろを回る）。最初にクリックでマウスを画面に固定（WebGL の仕様）。Esc で解除＝ポーズ
- W/A/S/D: 前後左右に飛ぶ ／ Space: 上昇 ／ Shift: 下降
- 左クリック長押し: 着地中の肌で吸血（離すと飛び立つ）
- 右クリック: 回避ダッシュ（向いている方向へ素早く移動、クールダウンあり）

## 実装前に報告する問題と対応案（Claude）

① **蚊が小さすぎて三人称視点が成立しにくい**
実寸（蚊 5mm・部屋 4m）では、カメラが近すぎて家具にめり込み、物理も不安定になる。
→ **世界全体を大きく作り**（蚊が約 0.5、人間が約 17 の大きさ）、カメラは蚊の少し後ろ上に置き、壁や家具に当たったら手前に寄せる。「巨大な部屋を飛ぶ蚊」の見え方になる

② **「発見」と「逃げ切り」の条件が資料にない**
→ 発見は「気づきゲージ」が満タンになったとき。ゲージは ①人間の視界（顔の向きの円すい）に入る ②耳の近くで羽音を立てる ③吸血中のかゆみ、で溜まり、離れると少しずつ減る。寝ているときは溜まりにくい。
逃げ切りは「攻撃中に人間の視界の外に一定時間（約5秒）いる」こと。物陰（枕の裏・ベッドの下・カーテンなど）に入ると見失われる

③ **攻撃が理不尽にならないようにする**
→ 叩く前に必ず予兆を出す（手を振りかぶる・叩く場所に影が落ちる・約0.6秒）。回避ダッシュで確実によけられる速さにする。当たり判定は手の形より少し小さめ

④ **終わりがスコア稼ぎだけで、ゲームオーバー以外に区切りがない**
→ 試作品では「叩かれたら終了」の1本道にする（完成条件の範囲）。満腹でクリア・朝までの制限時間などは次回候補に回す

⑤ **人間の見た目と動き**
人間のモデルと動き（寝返り・起き上がる・叩く）が必要。
→ Phase 1 は **箱や円柱を組み合わせた人形**（部位ごとに当たり判定を分けやすい）で、動きはコードで回転させて作る。Phase 2 で見た目を良くする方法（無料素材を使うか、組み合わせた人形を作り込むか）は、その時点で本人と相談する

⑥ **WebGL の制約**
→ ファイルが大きめ（目安 10〜30MB）で読み込みに少し時間がかかる。GitHub Pages で動かすため圧縮は「Gzip＋展開の予備処理」設定にする。マウスの固定は最初のクリックが必要。重くならないよう、影・ライトは控えめにする

⑦ **これまでのゲームと作り方が違う**
これまでは HTML を1枚にまとめて `verify.html` で確認していたが、今回は Unity。
→ 確認は Unity Editor 上（Unity MCP でプレイして動きとエラーを見る）と、ゲームの決まりごと（点数・ゲージ・判定）のテストで行う。WebGL での最終確認はビルドしてブラウザで開く

## 完成条件（本人確認済み）

部屋1つ・人間1人で、次が通しで遊べること。
1. 蚊を三人称視点で自由に飛ばせる（上昇・下降・回避ダッシュを含む）
2. 3部位以上（低・中・高リスク）で吸血でき、部位によって点数とバレやすさが違う
3. 気づきゲージが溜まると発見され、人間が攻撃してくる
4. 攻撃を回避して逃げ切ればスコアを持ったまま続行、叩かれたらゲームオーバー
5. 結果画面からリトライできる
6. WebGL ビルドがブラウザで動く
